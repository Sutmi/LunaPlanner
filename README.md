## 📱 Sobre el proyecto

**Luna Planner** es un proyecto Android desarrollado como base para una aplicación orientada a la organización y productividad personal.

El proyecto incorpora un sistema de autenticación que permite registrar usuarios, iniciar sesión y gestionar el acceso a la aplicación mediante Firebase.

Este proyecto forma parte de mi proceso de aprendizaje y desarrollo de aplicaciones móviles con Java y servicios en la nube.

---

## ✨ Funcionalidades implementadas

- 👤 Registro de usuarios
- 🔐 Inicio de sesión mediante correo y contraseña
- ✅ Validación de datos de acceso
- ☁️ Integración con Firebase Authentication
- 🗄️ Integración con Firebase Realtime Database
- 🚪 Cierre de sesión
- 📱 Interfaces desarrolladas para Android

## 🚧 Estado del proyecto

El proyecto se encuentra actualmente como **prototipo**.

La implementación disponible establece la base de autenticación y estructura inicial de la aplicación. Entre las posibles mejoras futuras se encuentran:

- Gestión de notas
- Creación y edición de contenido
- Organización por categorías
- Búsqueda de información
- Mejoras de interfaz y experiencia de usuario
- Actualización de arquitectura y dependencias
